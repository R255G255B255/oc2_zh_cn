# 内存
![随机存取存储器](item:oc2:memory_large)

随机存取存储器（RAM）为[计算机](../block/computer.md)和[机器人](robot.md)提供运行内存。

与[硬盘](hard_drive.md)不同，这种存储是易失性的，计算机关机时其中的数据会被清除。理论上，计算机可以不使用内存，只将硬盘用作程序运行时的临时数据存储；但常规程序通常需要内存才能运行。特别是新计算机的[固件](flash_memory.md)需要足够的内存。

同时快去看看[入门指南](../getting_started.md).

安装或移除新部件前，计算机*必须关机*。计算机运行时安装不会生效，移除则可能导致系统崩溃。
