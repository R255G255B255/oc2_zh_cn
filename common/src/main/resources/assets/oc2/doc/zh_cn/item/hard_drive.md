# 硬盘
![兜兜转转](item:oc2:hard_drive_large)

硬盘是[电脑](../block/computer.md)和[机器人](robot.md)用于存储数据的主要设备。

通常，电脑使用的固件需要硬盘才能完成启动。详情请参阅[闪存](flash_memory.md)条目。RISC-V Linux 需要与固件配套的根文件系统。可以将一块 8M 硬盘与[RISC-V处理器](cpu_riscv.md)合成来获取该文件系统；合成会将文件系统写入硬盘。

将合成后的硬盘与[扳手](wrench.md)合成，可以将其清空。

安装或移除此组件前，电脑*必须关机*。电脑运行时安装不会生效，移除则可能导致系统错误。

存储介质并非完美无缺。驱动器长期闲置可能会发生位衰减，导致其中的内容丢失。使用[扳手](wrench.md)格式化损坏的驱动器。有趣的是，这种情况似乎只会在世界中存在大量存储设备时发生。
