# Z80处理器
![思考组件](item:oc2:cpu_z80)

处理器是[电脑](../block/computer.md)和[机器人](robot.md)中实际用来计算的核心，如果处理器插槽中没有处理器，机器就无法启动。

这是8位Z80处理器。它的闪存中存放着一个启动加载器，用来从[软盘](floppy.md)启动 CP/M 2.2。无论你安装的是多大容量的内存模块，它都寻址64K的内存空间，而且它所需的外围硬件非常少。通过[MLAPI](../mlapi.md)提供的设备，例如[红石接口](../block/redstone_interface.md)，都能按预期工作。硬盘、网卡和其他原生设备则不会被使用，因为 Z80 没有对应的驱动程序。

另见[RISC-V处理器](cpu_riscv.md)。

## 启动

按照[入门指南](../getting_started.md)组装机器，所需部件如下：

- 1x [电脑](../block/computer.md)
- 1x Z80 处理器
- 1x [**CP/M**闪存固件](flash_memory.md)
- 1x 接在总线上的[磁盘驱动器](../block/disk_drive.md)，里面装有一张[**CP/M**软盘](floppy.md)
- 1x [内存](memory.md)，任意容量

给它通电并开机。引导程序会找到系统软盘，并把 CP/M 启动到提示符 `A>`。运行 `DIR` 可以查看磁盘中包含什么内容：

- `DEVS.COM` 会打印出机器当前能看到的设备
- `DEVLIB.INC` 和 `OCAPI.INC` 是你自己程序所需的库
- `REDSTN.Z80` 是一个入门示例
- `ZMAC.COM` 和 `ZML.COM` 分别是汇编器和链接器

驱动器 `A:` 就是你启动时使用的软盘，它可写。再加一个带空白软盘的 磁盘驱动器 用来扩展空间，它会显示为 `B:`。

[机器人](robot.md)自己有一个软盘槽，因此它可以不用磁盘驱动器也拥有系统盘。

此时你就可以根据用途继续添加更多设备。有关如何控制设备，以及如何构建和运行示例程序的信息，请查看[MLAPI](../mlapi.md)手册条目。

## 构建程序

你可以使用自带的 `ZMAC`（汇编器）和 `ZML`（链接器）来编译程序。

如果想把程序编译到第二个驱动器上，同时仍停留在 A: 盘上，可以执行以下操作：

`ZMAC REDSTN /OB:REDSTN /E`  
`ZML B:REDSTN`  
`B:REDSTN`

其中 `/O` 会把目标文件放到 `B:` 上，`/E` 会关闭错误日志。
