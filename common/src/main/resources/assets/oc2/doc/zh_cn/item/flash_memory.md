# 闪存
![不是那种闪存](item:oc2:flash_memory)

闪存中存放着电脑启动时加载到[电脑](../block/computer.md)内存中的初始代码。它包含固件，固件的功能仅限于找到要启动的系统并从驱动器加载该系统。

空白闪存不包含固件。要向其中写入固件，请将它与对应固件所适用的处理器合成：[RISC-V处理器](cpu_riscv.md)会写入 Linux 固件，[Z80处理器](cpu_z80.md)会写入 CP/M 固件。

这两种固件都不包含操作系统，因此机器还需要相应的存储介质：Linux 需要[硬盘](hard_drive.md)，CP/M 需要[软盘](floppy.md)。

你不必局限于 Linux 和 CP/M 这两种固件。[闪存驱动器](../block/flash_drive.md)会以普通块设备的形式向电脑提供闪存，因此你可以在上面写入任意内容。

将已写入程序的闪存与[扳手](wrench.md)合成，可以将其擦除并恢复为空白闪存；固件及其中存储的所有内容都会被丢弃。
