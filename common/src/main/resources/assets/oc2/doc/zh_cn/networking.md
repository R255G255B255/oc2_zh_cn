# 网络
要建立 [电脑](block/computer.md) 的网络，需要使用 [网络连接器](block/network_connector.md) 和 [网线](item/network_cable.md) 连接起互联网。 最后，确保在每台电脑都安装了 [网卡](item/network_interface_card.md)。

网络连接器必须连接到电脑的任意面，但不能连接到正面。 这样安装在电脑中的网卡就能通过连接器收发数据包。

连接在一起的连接口会将数据包互相转发。对于更复杂的网络结构，可能需要[网络集线器](block/network_hub.md)。它允许多个连接口互相连接。

## 跳数
网络数据包只能经过一定最大数量的“跳数”。一般来说，一跳可以理解为一次转发操作。 例如，网络连接器转发一个数据包会消耗一跳。当网络集线器从连接器接收到数据包，将数据包转发给其他连接器，也会消耗一跳。一旦剩余跳数降为0,数据包就不再被转发。这样可以避免数据包永远循环转发下去。也就是说，这是一个保护机制，任何网络都不应该包含循环，因为这样同一个数据包也会在接收端上重复到达多次。

## 设置电脑
要给电脑联网，首先要安装网卡，之后，使用默认的 Linux 发行版，运行命令 `setup-network.lua`。 这将提供一个向导来配置电脑应如何连接到网络。 如果你知道自己在做什么，也可以用常规方法手动配置网络，像普通Linux那样。

## DHCP
DHCP(动态主机配置协议)是一种能够简化网络配置的协议。只需要一台电脑配置静态网络地址，其余所有电脑都可以自动分配地址。使用这种配置时，要确保网络中只有一台电脑作为DHCP服务器，同时也要确保没有电脑使用静态IP可以落在动态分配地址的范围内。

`setup-network.lua` 会在你把一台计算机配置为 DHCP 服务器时启动。它不会在重启后保留。关于如何再次启动它，或者让它在启动时自动启动，请参见下文的“守护程序”部分。

## 指令工具
一旦网络配置正常运行，并且多个电脑处于同一网络中，你就拥有了很多选择。例如你可以使用`scp`在电脑之间复制文件，使用`ssh`登录到远程电脑，并使用Lua语言的`socket`库编写自定义网络程序。关于如何使用`socket`库的实力，请参见[官方仓库中的示例（外网）](https://github.com/diegonehab/luasocket/tree/master/samples)。

请注意，scp 和 ssh 是客户端工具。要从其他地方连接到一台电脑，需要它上面运行一个服务器。请参见下文的“守护程序”部分。

## 因特网
若想访问现实中的网络，该网络上需要有一个因特网网关。随后，计算机就可以用它们常规的网卡通过网关进行路由。

网关本身不提供 DHCP，也不提供名称服务器，所以你需要自己设置地址、路由和名称服务器。关于示例，请参见互联网网关条目。

## 守护程序
网络守护程序已经附带，但不会在启动时自动运行。你需要手动启动所需的守护程序：

`/etc/init.d/dropbear start` 用于 `ssh` 和 `scp` 服务器  
`/etc/init.d/telnet start` 用于 `telnet` 服务器  
`/etc/init.d/dnsmasq start` 用于 DHCP 服务器

`ssh` 服务器会拒绝任何账户密码为空的登录，而 `root` 默认就是空密码。因此，首次连接前请先用 `passwd` 设置密码。`telnet` 服务器没有这样的限制，它会直接接受空密码，所以任何能连接到该计算机的人都可以登录。

这些守护程序都不会在重启后保留。要让它们在开机时自动启动，请给对应脚本加上启动序号前缀：
`mv /etc/init.d/dropbear /etc/init.d/S50dropbear`
