# 网络
要建立计算机网络，需要使用[网络连接器](block/network_connector.md)和[网线](item/network_cable.md)连接各台计算机。最后，确保每台计算机都安装了[网卡](item/network_interface_card.md)。

网络连接器必须连接到计算机的任意一面，但不能连接到正面。这样，计算机中的网卡就能通过连接器收发数据包。

连接在一起的连接口会将数据包互相转发。对于更复杂的网络结构，可能需要[网络集线器](block/network_hub.md)。它允许多个连接口互相连接。

## 跳数
网络数据包只能经过一定最大数量的“跳数”。一般来说，一跳可以理解为一次转发操作。 例如，网络连接器转发一个数据包会消耗一跳。当网络集线器从连接器接收到数据包，将数据包转发给其他连接器，也会消耗一跳。一旦剩余跳数降为0,数据包就不再被转发。这样可以避免数据包永远循环转发下去。也就是说，这是一个保护机制，任何网络都不应该包含循环，因为这样同一个数据包也会在接收端上重复到达多次。

## 设置计算机
要让计算机联网，首先安装网卡，然后在默认 Linux 发行版中运行 `setup-network.lua`。该脚本会启动配置向导，帮助设置计算机的网络连接。你也可以像在普通 Linux 系统上一样手动配置网络。

## DHCP
DHCP（动态主机配置协议）可以简化网络配置：只需为一台计算机配置静态网络地址，其余计算机即可自动获取地址。使用这种配置时，要确保网络中只有一台计算机充当 DHCP 服务器，并且没有计算机使用落入动态分配地址范围的静态 IP。

`setup-network.lua` 会在你把一台计算机配置为 DHCP 服务器时启动。它不会在重启后保留。关于如何再次启动它，或者让它在启动时自动启动，请参见下文的“守护程序”部分。

## 指令工具
网络配置完成且多台计算机接入同一网络后，就可以使用 `scp` 在计算机之间复制文件、使用 `ssh` 登录远程计算机，或通过 Lua 的 `socket` 库编写网络程序。使用示例可参见[官方仓库中的示例（外部链接）](https://github.com/diegonehab/luasocket/tree/master/samples)。

请注意，`scp` 和 `ssh` 是客户端工具。要从其他位置连接到一台计算机，需要在该计算机上运行服务器。请参见下文的“守护程序”部分。

## 互联网
若要访问现实中的互联网，该网络上需要有一个互联网网关。之后，计算机就可以通过常规网卡经由网关路由流量。

网关本身不提供 DHCP，也不提供名称服务器，所以你需要自己设置地址、路由和名称服务器。关于示例，请参见互联网网关条目。

## 守护程序
网络守护程序已经附带，但不会在启动时自动运行。你需要手动启动所需的守护程序：

`/etc/init.d/dropbear start` 用于 `ssh` 和 `scp` 服务器  
`/etc/init.d/telnet start` 用于 `telnet` 服务器  
`/etc/init.d/dnsmasq start` 用于 DHCP 服务器

`ssh` 服务器会拒绝密码为空的账户登录，而 `root` 默认没有密码。因此，首次连接前请先用 `passwd` 设置密码。`telnet` 服务器没有这一限制，会直接接受空密码，所以任何能连接到计算机的人都可以登录。

这些守护程序都不会在重启后保留。要让它们在开机时自动启动，请给对应脚本加上启动序号前缀：
`mv /etc/init.d/dropbear /etc/init.d/S50dropbear`
