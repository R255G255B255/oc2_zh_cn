# 网络接口卡
![与陌生人对话](item:oc2:network_interface_card)

网络接口卡（NIC）允许[计算机](../block/computer.md)通过与其相连的[网络连接器](../block/network_connector.md)收发信息。

这些卡可以被设置为仅从特定的侧面进行连接(手持时使用网卡设置). 这样就可以，例如使用多张网卡组成一个自定义路由器

在使用默认 Linux 发行版时，该设备会提供一个标准以太网接口。网络既可以手动配置，也可以使用便捷脚本 `setup-network.lua`。脚本提供静态地址和 DHCP 两种配置方式；使用 DHCP 时，网络中必须有一台计算机充当 DHCP 服务器。

完成初次设置后，使用 `ifconfig` 命令以查看当前使用的IP。

安装或移除该组件前，必须先关闭计算机。计算机运行时安装不会生效，移除则可能导致系统错误。
