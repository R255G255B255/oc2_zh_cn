# 方块
该索引列出了所有已记录的方块。如果你在找的是物品，请改看 [物品索引](../item/index.md)。

要快速访问世界中某个方块的手册条目，只需拿着这个 [手册](../item/manual.md)对着方块使用即可，对于可交互的方块只需潜行时使用。

注意：大多数设备方块只接受单面的总线连接，即带有接口端口的那一面；[总线接口](bus_interface.md)只能连接到这个面。也有例外，例如 [红石接口](redstone_interface.md) 和 [转运器](transposer.md)，它们可以从多个侧面连接。
