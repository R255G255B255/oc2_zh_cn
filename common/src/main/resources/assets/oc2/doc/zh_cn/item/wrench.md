# 螺丝刀扳手
![撬动他!](item:oc2:wrench)

螺丝刀-扳手多用途工具,  可以用来直接访问一些方块的配置页面, 如 [电脑](../block/computer.md)。

它在配置如[总线接口](../block/bus_interface.md)时是必要的。 它也可以用来快速拆卸一些设备，例如 [线缆](../block/bus_cable.md)。

此工具还可用于从电缆上移除装饰。

他还可以清除[闪存](flash_memory.md)和[硬盘](hard_drive.md)的已有数据

*螺丝刀扳手原名为“Scrench”，即螺丝刀“Screwdriver”和扳手“wrench”的组合。*
